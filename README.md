# ตารางเก็บขยะ — Wat Phra Dhammakaya Bavaria

เว็บแอปแสดงวันที่รถขยะมาเก็บที่ **Heinkelstraße 1, 86343 Königsbrunn** ว่าวันไหนต้องนำถังอะไรออก
ข้อมูลมาจาก [AWB Landkreis Augsburg](https://www.awb-landkreis-augsburg.de/aktuelles/abfuhrtermine) และอัปเดตเองทุกวัน

- ใช้งานเหมือนแอป (ติดตั้งลงหน้าจอโฮมได้, ใช้ออฟไลน์ได้) แบ่งเป็น 3 แท็บ:
  **วันนี้** (การ์ด "คืนนี้ต้องนำถังออก" พร้อมภาพถังสีตามประเภท + แถบ 7 วันข้างหน้า + รายการถัดไป) · **ปฏิทิน** (รายเดือน, แตะวันเพื่อเปิดรายละเอียด, ปัดซ้าย/ขวาเปลี่ยนเดือน, ตัวกรองประเภท, สรุปจำนวนครั้งต่อเดือน) · **เพิ่มเติม**
  (ภาพถังเป็น SVG วาดเองใน `js/app.js` สีมาจาก CSS จึงเปลี่ยนตามโหมดสว่าง/มืด)
- ดึงหน้าจอลงเพื่ออัปเดตตาราง, ปุ่ม Back ของมือถือปิดหน้าต่างรายละเอียดแทนการออกจากแอป
- **แชร์** วันเก็บ/ตารางผ่าน LINE หรือข้อความ (ถ้าเครื่องไม่รองรับจะคัดลอกให้), **เพิ่มวันเก็บลงปฏิทินทีละวัน** (พร้อมแจ้งเตือน 18:00 น. คืนก่อน)
- **ฉากน่ารัก** ท้องฟ้าหลังหัวข้อเปลี่ยนตามสภาพอากาศจริงของ Königsbrunn (แดดจ้า เมฆ ฝน หิมะ พายุ หมอก) กลางวัน/กลางคืน และฤดู (ใบไม้ร่วงช่วง ก.ย.–พ.ย. กลีบดอกไม้ช่วง มี.ค.–พ.ค.) บนขอบการ์ดมีสวนเล็กๆ (ต้นไม้เปลี่ยนสีตามฤดู พุ่มไม้ ดอกไม้ ผีเสื้อ) แมวสีเทาชื่อ "มู่ทู่" กับน้องหมาเดินเล่นไปมา นกกระโดดและบินได้ ทุกตัวแตะแล้วจะทักทาย — ตั้งแต่ 22:00–06:00 จะหลับ หน้าหนาวใส่ผ้าพันคอ แดดจ้าใส่แว่นกันแดด ถังขยะมีหน้ายิ้มและกระโดดเตือนในวันเก็บ
- **ข่าวและกิจกรรมของเมือง** แท็บ "ข่าว": ข่าวของ Königsbrunn และ Augsburg กับกิจกรรมของ Königsbrunn (หัวข้อ + สรุปสั้นภาษาเยอรมัน) เลือกเปิดอ่านต้นฉบับเยอรมันหรือแปลเป็นไทยด้วย Google ได้ เพิ่มกิจกรรมลงปฏิทินได้
- **ขนาดตัวอักษร** 3 ระดับ (ปกติ / ใหญ่ / ใหญ่มาก) และโหมดสว่าง/มืด ในแท็บเพิ่มเติม
- ปุ่ม Subscribe ลงปฏิทิน (Apple / Outlook / Google), ดาวน์โหลด `.ics`
- ตารางทั้งปี A4 หน้าเดียว: ในเบราว์เซอร์กด "พิมพ์ตารางทั้งปี" (เลือก Save as PDF ได้) ส่วนในแอปที่ติดตั้งลงหน้าจอโฮมและบนมือถือ ใช้ "ส่งตารางทั้งปี (PDF / รูปภาพ)" → ดูตัวอย่าง → "แชร์ / พิมพ์" (บน iPhone เลือก "พิมพ์" ในเมนูแชร์) หรือ "บันทึกเป็นรูปภาพ" (ไฟล์ PNG; บน iPhone เลือก "บันทึกรูปภาพ" ในเมนูแชร์เพื่อเก็บลงอัลบั้ม) เพราะ `window.print()` ใช้ไม่ได้ในแอปที่ติดตั้งบน iPhone
- ประกาศจากแอดมิน และแจ้งเตือนทางอีเมลทุกเย็นก่อนวันเก็บ

ไม่มีเซิร์ฟเวอร์: เป็นไฟล์ static + GitHub Actions ที่ดึงข้อมูลทุกวัน

## ตั้งค่าถังที่องค์กรมีจริง (`enabledBins`)

ข้อมูลของ AWB ลิสต์ถังทุกแบบที่ถนนนี้ใช้ได้ (ทั้งแบบ Tonne และ Container) ถ้าเว้นว่าง (`null`) เว็บจะแสดงทั้งหมด
ให้ใส่เฉพาะแบบที่องค์กรมีจริง เช่น

```json
"enabledBins": ["restmuell-tonne", "biotonne", "altpapier-tonne", "wertstoff", "problemabfall"]
```

| key | ถัง | รอบเก็บ |
|---|---|---|
| `restmuell-tonne` | Restmülltonne 80/120/240 ลิตร | ทุก 2 สัปดาห์ |
| `restmuell-container` | Restmüllcontainer 770/1100 ลิตร | ทุกสัปดาห์ |
| `restmuell-container-2w` | Restmüllcontainer 770/1100 ลิตร | ทุก 2 สัปดาห์ |
| `biotonne` | Biotonne | ทุก 2 สัปดาห์ |
| `altpapier-tonne` | Altpapiertonne 240 ลิตร | ทุก 4 สัปดาห์ |
| `altpapier-container` | Altpapiercontainer 1100 ลิตร | ทุก 2 สัปดาห์ |
| `wertstoff` | Wertstofftonne / Gelber Container | ทุก 2 สัปดาห์ |
| `problemabfall` | Problemabfallsammlung (ขยะอันตราย) | รอบพิเศษ |

ดูว่าถังจริงเป็นแบบไหนได้จากฉลากบนถัง หรือสอบถาม AWB (โทร 0821 3102-3221 / abfallberatung@LRA-a.bayern.de)
หลังแก้ `config.json` แล้ว push ระบบจะสร้างไฟล์ปฏิทินและเว็บใหม่ให้เอง

## ประกาศจากแอดมิน (`data/announcements.json`)

แก้ไฟล์นี้ใน GitHub ได้เลย (ปุ่มดินสอ) — เว็บจะแสดงเฉพาะประกาศที่อยู่ในช่วงวันที่

```json
[
  {
    "type": "warning",
    "title": "วันหยุดเลื่อนเก็บ",
    "body": "สัปดาห์หน้ารถมาเก็บช้ากว่าปกติ 1 วัน\nกรุณาวางถังตามประกาศ AWB",
    "from": "2026-12-20",
    "until": "2027-01-03",
    "link": { "text": "ดูที่ AWB", "url": "https://www.awb-landkreis-augsburg.de/aktuelles/abfuhrtermine" }
  }
]
```

- `type`: `"warning"` (สีแดง) หรือไม่ใส่ (สีเหลือง) · `from` / `until`: ไม่ใส่ = ไม่จำกัด · `link` ไม่บังคับ
- เป็นข้อความธรรมดา (ไม่รองรับ HTML) · ประกาศที่ยัง active จะถูกแนบไปในอีเมลแจ้งเตือนด้วย
- วันหยุดนักขัตฤกษ์ที่ทำให้วันเก็บเลื่อน **อยู่ในตารางของ AWB อยู่แล้ว** ไม่ต้องแก้เอง

## ติดตั้งครั้งแรก (GitHub Pages)

1. สร้าง repository บน GitHub แล้ว push โค้ดนี้ขึ้นไป (branch `main`)
2. Settings → Pages → Source: **GitHub Actions**
3. แท็บ Actions → "Refresh data and deploy" → Run workflow (ครั้งแรกเว็บจะขึ้นภายในไม่กี่นาที)
4. เว็บอยู่ที่ `https://<ชื่อ-account>.github.io/<ชื่อ-repo>/`

หลังจากนั้นระบบดึงข้อมูลจาก AWB และ deploy เว็บใหม่เองทุกวัน (ไฟล์ใน `data/` จะถูก commit เฉพาะเมื่อตารางเปลี่ยน)
> หน้าเว็บบน GitHub Pages ฟรีเป็นสาธารณะ ซึ่งมีแค่ที่อยู่ขององค์กร (ข้อมูลสาธารณะอยู่แล้ว) ถ้าต้องการจำกัดเฉพาะสมาชิก ต้องเปลี่ยนที่โฮสต์

## ข่าวและกิจกรรมของเมือง

แท็บ "ข่าว" อ่านจากฟีดสาธารณะของเมือง (ผ่านสคริปต์ `scripts/fetch-news.mjs` ใน GitHub Actions — เบราว์เซอร์ไม่ต้องเรียกเว็บของเมืองเอง):

| แหล่ง | ข้อมูล | ฟีด |
|---|---|---|
| Stadt Königsbrunn | ข่าว + กิจกรรม | `koenigsbrunn.de/nachrichten/rss`, `/veranstaltungen/rss` (สถานที่จาก iCal ของเมือง) |
| Stadt Augsburg | ข่าว | `augsburg.de/aktuelles-aus-der-stadt/feed.rss` |
| Augsburg กิจกรรม / Landkreis | — | ไม่มีฟีด จึงมีแค่ลิงก์ไปเว็บไซต์ของเมือง/อำเภอ |

- เก็บเฉพาะ **หัวข้อ + สรุปสั้น (≤ ~300 ตัวอักษร) + ลิงก์ต้นฉบับ + ชื่อแหล่งที่มา** ไม่เก็บรูปหรือเนื้อหาเต็ม และอนุญาตเฉพาะลิงก์ `https` ของ koenigsbrunn.de / augsburg.de
- Impressum ของทั้งสองเมืองระบุว่า "การพิมพ์ซ้ำและการนำ Pressemitteilungen ไปใช้ทำได้เมื่อระบุแหล่งที่มา" ส่วนเนื้อหาอื่นของเว็บไซต์เป็นลิขสิทธิ์ของเมือง จึงแสดงแค่ข้อความสั้นพร้อมลิงก์ไปอ่านฉบับเต็ม
- **คำแปลไทยทำโดย Google Translate** ผ่านลิงก์ `*.translate.goog` (ไม่มีข้อความแปลเก็บไว้ในเว็บเรา) แตะข่าวหรือกิจกรรมในรายการจะเปิดแผ่นรายละเอียด มีปุ่ม "อ่านเป็นภาษาไทย" (หน้าเต็มที่ Google แปลให้) และ "อ่านต้นฉบับ (เยอรมัน)" ชัดเจนแยกกัน กิจกรรมเพิ่มลงปฏิทินได้ รายการจัดกลุ่มตามวัน (ข่าว) หรือเดือน (กิจกรรม)
- ถ้าฟีดไหนล่ม สคริปต์จะคงข่าวเดิมของแหล่งนั้นไว้ (ขึ้นหมายเหตุ "บางแหล่งอัปเดตไม่ได้ชั่วคราว") และไม่ทำให้การ deploy ตารางเก็บขยะล้ม (`continue-on-error`) ทดลองรันเองด้วย `node scripts/fetch-news.mjs`
- จะเพิ่มแหล่งใหม่: เพิ่มใน `SOURCES` ของสคริปต์ (โดเมนต้องอยู่ใน `ALLOWED_HOSTS`) และใน `TRUSTED_HOSTS` ของ `js/news.js`

## สภาพอากาศและฉากน่ารัก

อุณหภูมิและท้องฟ้าในแท็บ "วันนี้" อ่านจาก **สถานีวัดจริงของกรมอุตุนิยมวิทยาเยอรมัน (DWD)** ผ่าน [Bright Sky](https://brightsky.dev) (ใช้สถานีที่ใกล้ที่สุด เช่น Lechfeld ห่างราว 10 กม.) และใช้ค่าพยากรณ์จาก [Open-Meteo](https://open-meteo.com) เติมในส่วนที่ขาด ทั้งสองบริการฟรี ไม่ต้องสมัคร ไม่ต้องมีคีย์ และ **ส่งไปแค่พิกัดของเมือง ไม่มีข้อมูลของผู้ใช้**

ทำไมไม่ใช้ค่าพยากรณ์อย่างเดียว: ลองเทียบ 3 วันที่ผ่านมา ค่าจากโมเดลร้อนกว่าสถานีจริงเฉลี่ย +1.1 °C ตอนกลางคืน (ห่างสุด 3.3 °C) ส่วนตอนกลางวันใกล้เคียงกัน

- ค่าจากสถานีแสดงเป็น `16°` ส่วน `≈16°` แปลว่าเป็นค่าประมาณจากโมเดล เพราะดึงค่าสถานีไม่ได้
- สถานีรายงานทุกชั่วโมง เว็บจึงตรวจใหม่ทุก 20 นาที ค่าที่เก่าเกิน 90 นาทีจะไม่แสดงตัวเลข (แสดงแค่สภาพท้องฟ้า) ถ้าออฟไลน์ ท้องฟ้าจะแสดงตามเวลากลางวัน/กลางคืนและฤดูแทน
- อุณหภูมิเป็นของสถานีที่ห่างออกไปไม่กี่กิโลเมตร อาจต่างจากเทอร์โมมิเตอร์หน้าบ้านเล็กน้อยได้ (แดดส่อง ตึกบัง หมอกเฉพาะที่)

```json
"weather": { "enabled": true, "observations": true, "lat": 48.27, "lon": 10.89 }
```

ตั้ง `"observations": false` เพื่อไม่เรียก Bright Sky (ใช้โมเดลอย่างเดียว) หรือ `"enabled": false` เพื่อไม่ให้เว็บเรียกบริการสภาพอากาศเลย ทดสอบแต่ละฉากได้ด้วย `?sky=` ต่อท้าย URL (`clear`, `partly`, `cloudy`, `fog`, `drizzle`, `rain`, `snow`, `storm`) ใช้ร่วมกับ `?today=2026-10-26&time=21:00` เพื่อดูตอนกลางคืนได้

## โหมดสว่าง / มืด

เปลี่ยนได้สองทาง: ปุ่มกลมมุมขวาบน (พระจันทร์/ดวงอาทิตย์) สลับทันที หรือแท็บ **เพิ่มเติม → รูปลักษณ์** เลือก สว่าง / มืด / อัตโนมัติ
"อัตโนมัติ" ตามการตั้งค่าของเครื่องและเปลี่ยนตามทันที ค่าที่เลือกจำไว้ในเครื่อง (เบราว์เซอร์) ของแต่ละคน

ฟอนต์ San Francisco ของ Apple **ห้ามนำไฟล์มาโฮสต์บนเว็บ** (ลิขสิทธิ์อนุญาตเฉพาะการใช้บนแพลตฟอร์ม Apple) วิธีที่ถูกต้องคือสั่งให้ "เครื่องของผู้ใช้" ใช้ฟอนต์ระบบของตัวเอง
เว็บนี้จึงใช้ `-apple-system` / `ui-rounded` ซึ่งแสดงเป็น SF บน iPhone, iPad และ Mac โดยไม่ต้องดาวน์โหลดฟอนต์เพิ่ม
อุปกรณ์อื่น (Android / Windows) ใช้ฟอนต์ [Inter](https://rsms.me/inter/) (SIL Open Font License 1.1 — ใช้และแจกจ่ายได้ฟรี) เฉพาะตัวอักษรละติน
ส่วนภาษาไทยใช้ฟอนต์ระบบของเครื่องเสมอ ไฟล์ลิขสิทธิ์ของ Inter อยู่ที่ `licenses/Inter-LICENSE.txt` (ต้องแจกจ่ายไปพร้อมฟอนต์)

**ไอคอน:** SF Symbols ของ Apple ใช้บนเว็บไม่ได้เช่นกัน จึงใช้ [Phosphor Icons](https://phosphoricons.com) (MIT, © 2023 Phosphor Icons — ไฟล์ลิขสิทธิ์ที่ `licenses/Phosphor-LICENSE.txt`) ซึ่งมีแบบเส้น (regular) และแบบทึบ (fill) คู่กันเหมือน SF Symbols — แท็บที่เลือกจะเปลี่ยนเป็นแบบทึบ

## ติดตั้งเป็นแอปบนมือถือ

เปิดเว็บแล้วเลือกแท็บ **เพิ่มเติม → เพิ่มไว้ที่หน้าจอโฮม** (หรือกดปุ่ม "ติดตั้ง" ที่ท้ายหน้า "วันนี้") ถ้าอยากดูทีละขั้น เลือก **เพิ่มเติม → วิธีติดตั้งทีละขั้น** (เลือกระบบและเบราว์เซอร์ให้เองตามเครื่อง สลับดูของเครื่องอื่นได้)

- **iPhone / iPad:** ต้องใช้ Safari — แตะปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" → "เพิ่ม"
- **Android — Chrome:** กดปุ่ม "ติดตั้ง" ในเว็บ (ขึ้นหน้าต่างของระบบ) หรือเมนูสามจุด ⋮ → "ติดตั้งแอป" → "ติดตั้ง"
- **Android — Samsung Internet:** เมนูสามขีด ≡ (มุมขวาล่าง) → "เพิ่มหน้านี้ไปยัง" → "หน้าจอหลัก" → "เพิ่ม"
- **Android — Firefox:** เมนูสามจุด ⋮ → "ติดตั้ง" → "เพิ่มไปยังหน้าจอโฮม"
- ชื่อปุ่มอาจต่างกันเล็กน้อยตามรุ่นและภาษาของเครื่อง ถ้าไม่เห็นปุ่มติดตั้งให้ลองเปิดด้วย Chrome
- เมื่อติดตั้งบน Android ไอคอน "เก็บเพชรพลอย" จะอยู่ที่หน้าจอโฮมและลิ้นชักแอป กดค้างที่ไอคอนจะมีทางลัด "ปฏิทิน" ถอนการติดตั้งได้เหมือนแอปทั่วไป
- นี่คือ PWA (เว็บแอป) ไม่ใช่ไฟล์ APK / ไม่ได้อยู่ใน Play Store — ไม่ต้องมีบัญชีนักพัฒนาและอัปเดตเองทุกครั้งที่เปิดแอปตอนมีเน็ต
- เมื่อติดตั้งแล้วจะเปิดเต็มจอเหมือนแอป และใช้ได้แม้ไม่มีอินเทอร์เน็ต (แสดงตารางที่บันทึกไว้ล่าสุด)
  ตารางจะอัปเดตเองเมื่อเปิดแอปตอนมีเน็ต หรือดึงหน้าจอลงเพื่ออัปเดตทันที
- ระบบจำไว้ว่าแอปเปิดจากเว็บที่โฮสต์ไว้ — ถ้าย้ายไปโดเมนใหม่ ต้องติดตั้งใหม่
- เมื่อเพิ่มไฟล์ใหม่ที่หน้าเว็บต้องใช้ ให้เพิ่มชื่อไฟล์ในรายการ `PRECACHE` ของ `sw.js` ด้วย (ไม่เช่นนั้นไฟล์นั้นจะยังไม่ถูกเก็บไว้ใช้ออฟไลน์จนกว่าจะเคยเปิดแอปตอนมีเน็ต)
- แจ้งเตือนแบบ push บนมือถือยังไม่รองรับ (ต้องมีเซิร์ฟเวอร์ push) — ใช้อีเมลหรือการแจ้งเตือนของแอปปฏิทินแทน

## แจ้งเตือนทางอีเมล

ส่งทุกเย็น (~17:00 น. เวลาเยอรมนี) ถ้าพรุ่งนี้มีเก็บ — ถ้าไม่มีเก็บจะไม่ส่ง ผู้รับทุกคนอยู่ใน BCC

1. เตรียมบัญชี SMTP (เช่น Brevo, Mailjet, หรือ Gmail ที่เปิด App Password)
2. Settings → Secrets and variables → Actions → **Secrets** เพิ่ม:
   `SMTP_HOST`, `SMTP_PORT` (เช่น 587), `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` (เช่น `ตารางเก็บขยะ <noreply@example.org>`),
   `MAIL_TO` (อีเมลผู้รับคั่นด้วย comma)
3. ทดสอบ: Actions → "Evening e-mail notification" → Run workflow (ค่าเริ่มต้นเป็น dry run — ดูเนื้อหาใน log)
   แล้วลองรันอีกครั้งโดยเอาติ๊ก dry run ออกเพื่อส่งจริง (ถ้าพรุ่งนี้ไม่มีเก็บ จะไม่ส่ง)
4. เปิดการส่งอัตโนมัติ: Settings → Secrets and variables → Actions → **Variables** → เพิ่ม `NOTIFY_EMAIL` = `true`

> รายชื่อผู้รับและรหัสผ่านเก็บใน Secrets เท่านั้น ไม่อยู่ใน repository
> cron ของ GitHub ใช้เวลา UTC จึงคลาดเคลื่อน ±1 ชั่วโมงตามฤดูกาลเวลาออมแสง และอาจล่าช้าได้เล็กน้อย
> LINE: LINE Notify ปิดบริการแล้ว หากต้องการแจ้งเตือนทาง LINE ต้องสร้าง bot ผ่าน LINE Messaging API — ยังไม่รวมในเวอร์ชันนี้

## ใช้ปฏิทินในมือถือ

- **Apple / Outlook:** กดปุ่มแล้วเลือก Subscribe — อัปเดตเองเมื่อ AWB เปลี่ยนวัน และมีแจ้งเตือน 18:00 น. ของคืนก่อนวันเก็บ
- **Google Calendar:** กดปุ่มแล้วยืนยัน (Google ไม่แสดงการแจ้งเตือนของปฏิทินที่ subscribe — ตั้งแจ้งเตือนเองในการตั้งค่าปฏิทิน)
- **ดาวน์โหลด .ics:** นำเข้าครั้งเดียว ไม่อัปเดตอัตโนมัติ

## รันในเครื่อง / ทดสอบ

```bash
npm install                        # ครั้งแรก (ต้องใช้ Node 20+)
npm run fetch                      # ดึงข้อมูลจาก AWB → data/
npm run serve                      # เปิด http://localhost:8080
node scripts/notify.mjs --dry-run --today=2026-10-26   # ดูอีเมลที่จะส่งโดยไม่ส่งจริง
```

ทดสอบการแสดงผลตามวัน/เวลาอื่นด้วยพารามิเตอร์ใน URL (จะมีแถบ "โหมดทดสอบ" ขึ้นเตือน):
`http://localhost:8080/?today=2026-10-19&time=18:00` → การ์ด "คืนนี้ต้องนำถังออก"

## หมายเหตุสำคัญ

- **ที่มาของข้อมูล:** AWB แสดงปฏิทินผ่านระบบ C-Trace และเราดึงไฟล์ ICS ที่ระบบนั้นสร้างให้ — ไม่ใช่ API ที่ AWB ประกาศเป็นทางการ
  ถ้า AWB เปลี่ยนระบบ การดึงข้อมูลอาจล้มเหลว (workflow จะขึ้นสีแดงและเว็บยังแสดงข้อมูลเดิมที่เก็บไว้)
  ให้เทียบกับ [หน้าปฏิทินของ AWB](https://www.awb-landkreis-augsburg.de/aktuelles/abfuhrtermine) เป็นระยะ
- **ปีถัดไป:** AWB ประกาศตารางปีหน้าช่วงพฤศจิกายน ก่อนหน้านั้นหน้าเว็บจะแจ้งว่า "ยังไม่ประกาศ" และดึงเข้าให้เองทันทีที่ประกาศ
- **Problemabfallsammlung** (ขยะอันตราย) เป็นรอบพิเศษ ไม่ใช่วันวางถัง — เว็บจะไม่แสดงกฎ "วางก่อน 06:30" สำหรับวันนั้น และแนะนำให้ดูเวลา/จุดรับที่ AWB
- เว็บใช้เวลา Europe/Berlin เสมอ ไม่ว่าผู้ชมจะอยู่ที่ไหน
- เว็บนี้ไม่ใช่เว็บทางการของ AWB — หากวันที่ไม่ตรงกัน ให้ยึดตามประกาศของ AWB
